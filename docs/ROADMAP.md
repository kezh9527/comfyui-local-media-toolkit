# Roadmap

This roadmap covers the derivative local-toolkit layer. Upstream ComfyUI
development remains in the upstream repository.

## Near Term

- Add focused tests for local image cleanup, API request validation, and job
  lifecycle behavior.
- Publish a reproducible Windows setup matrix for CPU and GPU environments.
- Add synthetic or explicitly authorized demo assets and screenshots.
- Improve error messages for missing FFmpeg, models, and optional dependencies.

## Later

- Package local-toolkit installation separately from the upstream workspace.
- Add cross-platform helper scripts where dependencies support them.
- Add structured release notes and migration guidance for configuration changes.

Contributions should preserve the source-only publication boundary and the
responsible-use guidance.
