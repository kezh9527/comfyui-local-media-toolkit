# Responsible Use

This project provides local media editing utilities. Use them only for lawful,
authorized purposes.

## Appropriate Uses

- Editing media you created or are authorized to modify.
- Removing an overlay you added yourself when restoring a clean master.
- Internal testing, education, and research with properly licensed assets.
- Face replacement with the informed consent of the depicted people.

## Do Not Use This Project To

- Remove ownership, attribution, provenance, or rights-management markings from
  media when you do not have permission.
- Download, republish, or modify media in violation of copyright law or platform
  terms.
- Impersonate a person, create deceptive media, or perform non-consensual face
  replacement.
- Conceal the origin of synthetic or edited media when disclosure is required.
- Process private, sensitive, or biometric data without authorization.

## Operational Notes

- Keep the launcher and API bound to `127.0.0.1` unless you add access controls.
- Treat custom nodes, model files, and downloaded optional projects as
  third-party software.
- Preserve original media separately. Cleanup and generative edits can be
  irreversible.
